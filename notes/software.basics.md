# Engenharia de Software — Conceitos Fundamentais

## Definições Básicas

### Software
Programa de computador, procedimentos e documentação associada.

### Sistema
Combinação de elementos interligados e organizados de forma a atender um propósito.

### Sistema de Software
Sistema que contém um software importante para os *stakeholders* (partes interessadas).

### Programa de Computador
Combinação de instruções em código que vão acionar algum serviço e definições que instruam o hardware a atuar de alguma forma.

---

## Paradigmas de Programação

Estilo/modo de se programar — **independe da linguagem**.

| Paradigma | Descrição |
|---|---|
| **Procedural** | O programa é uma sequência de instruções/procedimentos executados em ordem |
| **Orientado a Objetos** | O programa é organizado em objetos que possuem atributos e comportamentos |
| **Funcional** | O programa é composto por funções puras, sem efeitos colaterais |

---

## Linguagem de Programação

Conjunto de regras e símbolos usados para escrever programas. Cada linguagem pode suportar um ou mais paradigmas.

> Exemplos: Python (multi-paradigma), Java (OO), C (procedural), Haskell (funcional).

## Produtos Genéricos vs. Produtos sob Encomenda

| | **Produto Genérico** | **Produto sob Encomenda** |
|---|---|---|
| **Quem define os requisitos?** | A própria empresa desenvolvedora | O cliente contratante |
| **Exemplos** | Microsoft Office, Photoshop, aplicativos de celular | Sistema interno de uma empresa, ERP customizado |
| **Vendido para** | Qualquer pessoa/empresa | Um cliente específico |
